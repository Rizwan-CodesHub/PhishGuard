
# PhishGuard - Phishing URL Awareness Checker

## About the Project
PhishGuard is a Python-based application that analyzes website URLs
and identifies suspicious characteristics that may indicate phishing.

It uses a rule-based detection system to calculate a risk score.

## Features
- URL scanning
- Suspicious keyword detection
- HTTPS verification
- IP address detection
- URL length analysis
- Risk score calculation
- Low, Medium and High risk classification
- Graphical User Interface
- Recent scan history

## Technologies Used
- Python
- Tkinter
- Regular Expressions
- URL Parsing

## Project Structure

PhishGuard/
- main.py
- scanner.py
- README.md

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

python main.py

## Disclaimer
This is an educational project.
It uses basic URL pattern analysis and cannot guarantee
whether a website is safe or malicious.

Always verify websites through trusted sources.
